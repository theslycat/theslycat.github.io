4 阶行列式（点击元素展开）
选中的余子式 Mij
点击左侧任意元素开始。选定一行（或一列）把 4 个元素的 aijAij 全部加齐，就得到整个行列式的值。
符号表 (−1)i+j：+ − + − / − + − + / + − + − / − + − +（棋盘式，左上角起为正）。
经验：选 0 最多的行或列 展开最省力——这就是「0 越多越容易算」。
另一个方向：若拿另一行的元素来乘这些余子式，和为 0（定理 2.4）——这正是 AA* = |A|E 的证明核心。
