§1 映射与函数（4 题）

📇 讲解卡片 · 定义域、初等函数与周期性

项目 要点
定义域 使表达式有意义的 x 集合，各约束条件取交集：分式分母 ≠ 0；偶次根号内 ≥ 0；对数真数 > 0；arcsin / arccos 的自变量 ∈ [−1, 1]
初等函数 由基本初等函数经有限次四则运算和复合构成、且能用一个解析式表示的函数。判据是「本质结构」，不是「是否分段写出」——|x| = √(x²) 就是初等函数
周期性 sin(ωx)、cos(ωx) 的最小正周期 T = 2π/ω；常数函数无最小正周期；「+2」这类常数项不改变周期
⚠️ 易错 定义域条件取并集；cos(πx) 的周期误答 2π；以为分段函数一定不是初等函数

题 1 · 主观题（10 分）

课件 1.1 P42–43

题目：设 f(x) 为二次函数，且 f(x+1) + f(x−1) = 2x² − 4x，求 f(x)。

答案：f(x) = x² − 2x − 1

解析：设 f(x) = ax² + bx + c，则

f(x+1) + f(x−1) = a[(x+1)² + (x−1)²] + b[(x+1) + (x−1)] + 2c
                = 2ax² + 2bx + (2a + 2c)

与 2x² − 4x 比较系数：a = 1，b = −2，由 2a + 2c = 0 得 c = −1。故 f(x) = x² − 2x − 1。

💡 思路与数学思想 · 恒等式与待定系数

思路：题目只说 f 是二次函数而没给具体形式——这是「形式已知、参数未知」的标准信号，直接设出一般式，把条件代入，让恒等式两边的系数自己「说话」。不需要任何技巧，需要的是「把一般式写出来」的条件反射。

隐藏的数学思想：① 恒等式 ⇔ 系数全相等：两个多项式恒等，当且仅当同次幂系数相同，这是「同一对象的两种写法必须逐项吻合」。② 更深一层，这是差分思想的萌芽：注意到 f(x+1) + f(x−1) − 2f(x) = 2a（常数）——二阶差分提取了二次项。等到学了导数回头看：二阶差商的极限就是 f″(x)。「差分」是离散世界的求导，「系数比较」是离散世界的待定系数法，二者在后面解微分方程、做泰勒展开时都会反复出现。

题 2 · 单选题（5 分）

课件 1.1 P47

题目：练习题：判断下列函数是否为初等函数。 (1) y = √(1−x²)　　(2) y = |x|

选项：

  • A. (1) 是，(2) 否
  • B. (1) 是，(2) 是
  • C. (1) 否，(2) 否
  • D. (1) 否，(2) 是

答案：B（均为初等函数）

解析：(1) 由基本初等函数 y=√u 与 u=1−x² 复合而成；(2) |x| = √(x²)，同样由基本初等函数复合而成。能否用一个解析式表示是唯一判据，与是否「分段写出」无关。

💡 思路与数学思想 · 表示与本质

思路：见到带绝对值的函数，第一反应应该是「能不能脱掉绝对值写成别的形式」。|x| 的配方是 √(x²)——一层窗户纸，捅破了就是初等函数。对照：符号函数 sgn x 在 x=0 处无法用单一解析式与两侧衔接，才是真正的非初等函数。

隐藏的数学思想：写法 ≠ 对象。数学对象是它结构本身，表达式只是「衣服」。分段写出的函数未必是分段对象，解析式丑陋的函数未必结构复杂。后面学泰勒展开时同样如此：一个函数「看起来不是多项式」，在每一点附近却可以展成多项式——形式会骗人，结构不会。

题 3 · 单选题（5 分）

课件 1.1 P48

题目：函数 y = 3^√(3−x) + arccos((x+1)/2) 的定义域是

选项：

  • A. x ≤ 3
  • B. [−3, 1]
  • C. [−3, 1)
  • D. (−3, 1)

答案：B

解析：指数中的算术根要求 3−x ≥ 0，即 x ≤ 3；反余弦要求 −1 ≤ (x+1)/2 ≤ 1，即 −3 ≤ x ≤ 1。取交集得 [−3, 1]。注意 x ≤ 3 这个条件已被 [−3,1] 自动包含。

题 4 · 单选题（5 分）

课件 1.1 P49

题目：函数 f(x) = 2 + cos πx 的最小正周期是

选项：

  • A. 0
  • B. 2π
  • C. 2
  • D. π

答案：C

解析：T = 2π/π = 2。常数项「2」只做上下平移，不改变周期；而 cos(x) 的周期 2π 不能直接搬。

§2 数列的极限（4 题）

📇 讲解卡片 · ε–N 定义与收敛数列性质

项目 要点
定义 lim x_n = a ⇔ ∀ε>0，∃N∈N⁺，当 n>N 时恒有 |x_n − a| < ε
三要素 ε 任意小（挑战者）→ N 随之存在（应战）→ n>N 后所有项无一例外。N 不唯一，取大不取小
证明套路 从 |x_n − a| < ε 反解出 n 的范围，据此取 N
性质 唯一性；有界性（收敛 ⇒ 有界，反之不然）；保号性；子列定理：{x_n}→a ⇒ 任意子列 →a；两子列极限不同 ⇒ 原列发散
⚠️ 易错 把「无限个点落入邻域」当成收敛；几何意义中说成「所有点都落在邻域内」（是「至多有限个在外」）

题 5 · 单选题（5 分）

课件 1.2 P17

题目：关于 ε–N 定义的几何意义，判断： (1) ∀ε>0，当 n>N 时，无限个点都落在 U(a,ε) 内，则 lim x_n = a； (2) ∀ε>0，当 n>N 时，所有的点 x_n 都落在 U(a,ε) 内，而只有有限个 x_1,…,x_N 在外，则 lim x_n = a； (3) ∀ε>0，只有至多有限项 {x_n} 在 U(a,ε) 外，则 lim x_n = a。

选项：

  • A. (1) 对；(2) 对；(3) 对
  • B. (1) 不对；(2) 对；(3) 对
  • C. (1) 不对；(2) 不对；(3) 对
  • D. (1) 不对；(2) 不对；(3) 不对

答案：B

解析：(1) 「无限个点在内」留下了后门——邻域外还可以有无限个点。反例：x_(2k) = 0，x_(2k−1) = 2k，取 a=0：任意 U(0,ε) 都含有无穷多个偶数项点，但数列无界、不收敛。(2) 与定义逐字等价（「只有有限个在外」的另一种说法）；(3) 是 (2) 的等价改装。

💡 思路与数学思想 · 量词的力量

思路：判断这类「定义辨析题」，不要去「证明」，去找反例——每个命题问自己：它排除了哪些坏情况？(1) 没有排除「在外项无穷多」，所以一击即破。

隐藏的数学思想：极限定义的本质是全称量词 ∀ 与存在量词 ∃ 的对抗：∀ε（对手任意小）∃N（我总能应战）。「无限个点在内」只提供了 ∃，「所有 n>N 的点在内」提供的是 ∀——量词换一个，命题就从「极限」退化成「曾经过靠近」。数学的严谨，一大半就是量词的严谨。

题 6 · 主观题（10 分）

课件 1.2 P24–25

题目：练1：用定义证明数列 (1/n)·sin(nπ/4) 的极限是 0。

答案：证明见解析（N = ⌈1/ε⌉ + 1）

解析：∀ε>0，要使 (1/n)·|sin(nπ/4)| < ε，利用 |sin(nπ/4)| ≤ 1 放缩：只需 1/n < ε，即 n > 1/ε。取 N = ⌈1/ε⌉+1，则当 n>N 时 (1/n)|sin(nπ/4)| ≤ 1/n < ε。故极限为 0。

💡 思路与数学思想 · 放缩法

思路：ε–N 证明的标准动作是放缩：把估计不动的量（sin(nπ/4) 随 n 剧烈振荡，无法精确控制）用最粗的下界 |sin|≤1 扔掉，剩下能精确控制的量 1/n。

隐藏的数学思想：「容忍误差的艺术」。我们从来不追求精确值，只追求「能压到多小就多小」。sin 项虽然逐项不可预测，但它有界——而有界性足以保证它被 1/n 逐渐「闷死」。这就是「有界 × 无穷小 = 无穷小」在定义层面的样子，也是后面夹逼准则的思维方式：抓住主要矛盾，容忍次要扰动。

题 7 · 单选题（5 分）

课件 1.2 P39

题目：思考：lim x_n = a ⇔ lim |x_n| = |a| 是否成立？

选项：

  • A. 是
  • B. 否
  • D. 与 a 的值有关

答案：D（与 a 的值有关）

解析：⇒ 方向恒成立：||x_n| − |a|| ≤ |x_n − a| → 0（反向三角不等式）。⇐ 方向分情况：a≠0 时，最终 |x_n| > |a|/2，x_n 与 a 同号，可推出 x_n→a；a=0 时反例 x_n = (−1)ⁿ：|x_n|→0 但 x_n 发散。所以当且仅当 a≠0 时等价——「与 a 的值有关」。

💡 思路与数学思想 · 绝对值是「丢信息」的操作

思路：证「⇔」型命题，只需在一个方向找到反例。本题先保住容易的 ⇒，再专攻 ⇐：a=0 时符号信息最容易被抹掉——(−1)ⁿ 是教科书级反例。

隐藏的数学思想：取绝对值等价于「只保留到原点的距离，丢弃方向」。信息丢失的操作不可逆：距离→0 不能反推「物体停在原点」（它可能在原地振荡）。这与「|x_n − a|→0 推不出 x_n→±a」同源——绝对值把两根射线叠成了一根。做极限题时，看到绝对值就要警觉：符号信息还在吗？

题 8 · 单选题（5 分）

课件 1.2 P38

题目：思考：如果一个数列有两个收敛于相同极限的子列，该数列是否收敛？

选项：

  • A. 收敛
  • B. 不收敛
  • C. 可能收敛也可能不收敛

答案：C

解析：收敛数列的一切子列都收敛于同一极限，所以「可能收敛」。但两个子列未必「分工覆盖」全列：反例 x_n = 1（当 n = 2^k），x_n = 0（其余）。子列 {x_(2^k+1)} 全为 0 → 0，子列 {x_(3^k)}（3^k 不是 2 的幂）也全为 0 → 0，但原数列在 0 与 1 之间无限跳动，发散。故「可能收敛也可能不收敛」。

💡 思路与数学思想 · 抽检与全覆盖

思路：子列是「抽检」——抽两次合格，不代表整批合格，除非这两次抽检恰好分工覆盖全部项。课件中的推论 2 正是这个意思：奇子列与偶子列是两个天然分工的子列，它们同极限 ⇒ 全列收敛；而任意两个子列没有这个保证。

隐藏的数学思想：「两个子列同极限 ⇒ 收敛」这个直觉错在哪？错在把「部分」当成了「全部」。数学里「部分反映整体」永远需要额外条件（此处的额外条件就是「这两支覆盖了全列」）。奇偶分治是这个思想最漂亮的应用：把无限多个项「分拣」到两个篮子里，逐个击破。

§3 函数的极限（3 题）

📇 讲解卡片 · 单侧极限与极限存在性

项目 要点
核心判据 lim(x→x₀) f(x) 存在 ⇔ 左极限、右极限都存在且相等（双侧「会师」）
分侧信号 见到 |x|、sgn x、分段函数、e^(1/x)、x→0 的端点——条件反射：分左右！
与函数值 lim(x→x₀) f(x) 研究的是「趋近过程」，与 f(x₀) 有没有定义、值是多少完全无关
⚠️ 易错 把分段点的极限算成「某一侧的值」；把「极限存在」与「连续」混为一谈

题 9 · 单选题（5 分）

课件 1.3 P28

题目：练习1：判断极限 lim(x→0) |x|/x 是否存在？

选项：

  • A. 极限存在等于 1
  • B. 极限存在但不等于 1
  • C. 极限不存在
  • D. 不确定

答案：C

解析：|x|/x = 1（x>0）或 −1（x<0），即符号函数。右极限 1，左极限 −1，两侧「会师」失败。

💡 思路与数学思想 · 极限必须双侧会师

隐藏的数学思想：|x|/x 是一个「只输出符号、不输出大小」的函数。极限存在意味着「从哪个方向靠近都得到同一个数」；而符号函数在原点两侧给出两个不同的「方向回答」。这正是「连续」的直观原型：一条不断开的线，从左边摸到 0 和从右边摸到 0，指尖必须落在同一个高度。

题 11 · 课堂投票 · 思考

课件 1.3 P40

题目：若 lim(x→x₀) f(x) 存在，f(x₀) 也存在，是否一定有 lim(x→x₀) f(x) = f(x₀)？

选项：

  • A. 一定有
  • B. 不一定

答案：B

解析：连续需要三个条件同时成立：f(x₀) 有定义、极限存在、二者相等。反例：f(x) = x（x ≠ 0）而 f(0) = 1：lim = 0，但 f(0) = 1。极限值与函数值可以「脱钩」——可去间断点就是活证据。

§4 无穷小与极限的运算法则（3 题）

📇 讲解卡片 · 无穷小、有界性与 ∞/∞ 型

项目 要点
无穷小 以 0 为极限的变量（不是「很小的数」——再小的常数也不是无穷小）
运算法则 有限个无穷小的和差积仍是无穷小；有界 × 无穷小 = 无穷小（无穷小不能作除数）
∞/∞ 型 抓住「头尾」：最高次幂与系数的比值定生死，低次项是噪音
爆炸点 e^(1/x)、1/x 在 x=0，ln x 在 x=0 或 +∞——必须分侧
⚠️ 易错 「有界 × 无穷小」漏看有界因子；√(x²) = |x| 的隐藏绝对值在 x→−∞ 时变号

题 12 · 主观题（10 分）

课件 1.4–1.5 P12–13

题目：练1：求 lim(x→∞) 1/[x(1 + e^x)]。

答案：0

解析（课件官方解法）：拆成 (1/x)·[1/(1+e^x)]：lim(1/x) = 0（无穷小），而 |1/(1+e^x)| ≤ 1（有界）。有界函数与无穷小之积是无穷小，故原极限为 0。

💡 思路与数学思想 · 先拆因子，再各找定位

思路：复杂式子求极限，先「拆」：把式子拆成若干因子的积，再逐个问——谁是无穷小？谁有界？1/e^x 被指数「闷杀」在分母里，这个因子天然有界；1/x 是现成的无穷小。两者一相逢，极限归零。

隐藏的数学思想：结构性拆解。数学中「复杂」往往意味着「层次」——一项复杂表达式的极限，通常由它最慢衰减的那个因子决定（此处 1/x 是多项式衰减，比 1/e^x 的指数衰减慢得多，所以由它「定调」）。这种「找定调因子」的思维，就是后面阶的分析（∞/∞ 比速度）的雏形。

题 13 · 单选题（3 分）

课件 1.4–1.5 P47

题目：练2：求 lim(x→∞) [(2x−1)^30·(3x−2)^20] / (2x+1)^50。

选项：

  • A. ∞
  • B. 3/2
  • C. (3/2)^20
  • D. (3/2)^30

答案：C

解析：「头尾法」：x→∞ 时 (2x−1)^30 ~ (2x)^30，(3x−2)^20 ~ (3x)^20，(2x+1)^50 ~ (2x)^50。分子 x 的总幂次 30+20=50，分母也是 50，恰好抵消；剩下 2^30·3^20 / 2^50 = 3^20/2^20 = (3/2)^20。

💡 思路与数学思想 · 渐近分析：只听最高次项的声音

思路：幂次要「先记账再比较」：分子 50 次、分母 50 次，账面上打平，所以极限是有限非零常数——答案必是「某个常数」，∞（选项 A）直接排除。严谨版写法：每个因子提出主项，(2x−1)^30 = (2x)^30·(1 − 1/(2x))^30，每个修正因子都 →1，剩下的就是主项的比。

题目：练1：求极限 lim(n→∞) [1/(n³+1) + 2²/(n³+2) + … + n²/(n³+n)]，即 lim(n→∞) Σ(k=1→n) k²/(n³+k)。

答案：1/3

解析（夹逼准则，课件解法）：记和为 S_n。对每一项，分母中 n³+k 满足 n³ ≤ n³+k ≤ n³+n（k=1,…,n），故

(1²+2²+…+n²)/(n³+n) ≤ S_n ≤ (1²+2²+…+n²)/n³

代入 1²+2²+…+n² = n(n+1)(2n+1)/6：右边 = (1/6)(1+1/n)(2+1/n) → 1/3；左边同趋于 1/3。由夹逼准则，原极限 = 1/3。

💡 思路与数学思想 · 夹逼：把扰动关进笼子

思路：这道题是「n 项和、每项还在变」的结构，逐项求极限再求和行不通（项数无穷）。突破口是观察分母：扰动 k 相对于主项 n³ 是低阶的（k ≤ n ≪ n³）——于是把 k「关进笼子」：最小取 1、最大取 n，分母被夹在 n³ 与 n³+n 之间。笼子两端的和式都只含 Σk² 这一个可求和的部分，极限立刻可算。夹逼的本质：承认扰动存在，但证明它无害。

隐藏的数学思想：① 主项决定论：和的极限由「头」（分子 Σk² ~ n³/3）与分母的主项 n³ 决定，比值 1/3；扰动 k 无论怎么分布都不影响结局。② 这是黎曼和与积分思想的萌芽：Σf(k/n)·(1/n) 型和的极限是定积分，本题 S_n = Σ[(k/n)²/(1+(k/n)·(1/n²))]·(1/n) → ∫₀¹ x² dx = 1/3——离散和的极限「连续化」成积分，答案在更高的视角下是一眼看穿的。学期末学完定积分定义后，值得回来重看这道题。

答案：证明见解析

解析（辅助函数 + 零点定理）：构造 g(x) = f(x) − f(x+a)，x ∈ [0, 1−a]（关键：把定义域收缩，保证 x+a 不跑出 [0,1]）。 g 在 [0, 1−a] 上连续，且 g(0) = f(0) − f(a) = −f(a) ≤ 0；g(1−a) = f(1−a) − f(1) = f(1−a) ≥ 0（用非负性）。 若某端点已为 0，则对应的 ξ = 0 或 ξ = 1−a 即为所求；否则两端异号，由零点定理，∃ξ ∈ (0, 1−a) ⊂ [0,1)，使 g(ξ) = 0，即 f(ξ) = f(ξ+a)。∎

💡 思路与数学思想 · 构造类证明的教科书范例（本章最值得反复咀嚼的一道题）

思路拆解（四步构造法）：

  • ① 翻译：「存在 ξ 使两值相等」的 standard 翻译是「移项作差造函数」——g(x) = f(x) − f(x+a)，等式证明瞬间变成「找零点」。
  • ② 收缩：造出 g 后第一件事是看它的「合法活动范围」：x+a ≤ 1 要求 x ≤ 1−a——定义域意识是构造题的隐形考点，区间不收缩，f(x+a) 直接越界。
  • ③ 供血：端点值 g(0) = −f(a) ≤ 0、g(1−a) = f(1−a) ≥ 0——一正一负的「供血」恰好来自题设：f(0)=f(1)=0 负责「清零」，非负性负责「定向」。题设的每个条件都在构造中扮演了角色——这是检验构造是否正确的试金石。
  • ④ 收割：零点定理一键收割；端点已为零的退化情形单独交代，证明才严密。

隐藏的数学思想：① 介值性是「不跳跃」的拓扑代价：连续函数从一地到另一地，必须经过中间每一个值——零点定理只是介值定理撞上 0 的特例，而它的背后是实数轴的连通性。拓扑不变性（连续映射把连通集映到连通集）是这道题在现代数学中的「真身」：一条连着的曲线，水平移动 a 后必然与自身相交。② 辅助函数思想：把「两个对象的关系」（f(ξ) 与 f(ξ+a)）转化成「一个对象的性质」（g 的零点）——降维：二元关系 → 一元方程，这是数学最常用的偷换。③ 这道题与 Bolzano 定理、不动点定理（Brouwer 一维版：「[0,1] 的连续自映射必有不动点」）一脉相承——期中之后学微分中值定理、不等式的证明，辅助函数法会一再出现。现在把它啃透，是在为半张试卷的证明题练兵。

§9 导数的概念（2 题）

📇 讲解卡片 · 导数定义、可导与连续的关系

项目 要点
定义 f′(x₀) = lim(Δx→0) [f(x₀+Δx)−f(x₀)]/Δx，是双侧极限。几何意义：切线斜率；物理意义：变化率
关系链 可导 ⇒ 连续（连续是必要的，不是充分的）；连续 ⇏ 可导。经典反例：|x|、sin|x|、∛(x²)（尖点 / 折点 / 尖点）
分段点 先用函数值「接头」验证连续，再用左右导数「接斜率」验证可导——两个方程，常解两个参数
⚠️ 易错 只算右导数；把 f′(x₀) 存在与 f 在 x₀ 附近可导混为一谈；抽象函数求导忘记链式法则内层

题 24 · 单选题（5 分）

课件 2.1 P15

题目：练1：判断函数 f(x) = sin|x| 在 x = 0 处的连续性与可导性。

选项：

  • A. 连续且可导
  • B. 连续但不可导
  • C. 不连续但可导
  • D. 不连续且不可导

答案：B

解析：连续性：|sin|x|| ≤ |x| → 0 = f(0)，连续。可导性：

  • 右导数 lim(h→0⁺) (sin h − 0)/h = 1；
  • 左导数 lim(h→0⁻) [sin(−h) − 0]/h = lim (−sin h)/h = −1。

左右导数不相等 ⇒ 不可导。

💡 思路与数学思想 · 折点的「遗传」

思路：sin|x| 的图象是「正弦波的右半支不动、左半支关于原点翻折」——在 0 点形成一个尖点。几何直观先行：可导的图形必须光滑（切线唯一），尖点处切线「既可以是左边斜率也可以是右边斜率」，直接判「不可导」，再用左右导数计算坐实结论。

隐藏的数学思想：① |x| 的折点被复合函数 sin·|·|「遗传」给了 sin|x|：外层 sin 是光滑的，但它只改变内层的「幅度」，不消灭内层在 0 点的斜率突变（左侧斜率 −1，右侧 +1，被 sin 的局部线性性「等比例」保留）。② 反过来看：可导 ⇒ 局部线性。f(x) ≈ f(x₀) + f′(x₀)(x−x₀)——可导的本质是「在局部可以被一条直线冒充」。sin|x| 在 0 点无法被任何单一直线冒充，所以不可导。这个「局部线性化」观点，是后面微分、泰勒展开、牛顿迭代的共同基石。

课件 2.1 P46

题目：练2：设函数 f(x) = { √(1−x)，x ≤ 0 且 a(x−1)+b，x > 0 }，确定 a, b 的值，使 f(x) 在 x = 0 处可导。

即：

        { √(1−x),    x ≤ 0
f(x) =  {
        { a(x−1)+b,  x > 0

选项：

  • A. a = −1/2，b = −1/2
  • B. a = −1/2，b = 1/2
  • C. a = 1/2，b = −1/2
  • D. a = 1/2，b = 1/2

💡 思路与数学思想 · 接头考试：先接值，再接斜率

思路：分段函数可导性参数题是「流水线题型」，格式固定：连续给一个方程（值接头），可导再给一个方程（斜率接头），两个方程解两个参数。顺序不能反——可导必先连续，而且左右导数的计算要以各自的表达式为准。

隐藏的数学思想：「接头」的比喻背后是相容性思想：两个表达式在接头点必须「值相同、斜率相同」，才能拼成一条光滑曲线。斜率接头 (a=−1/2) 比值接头「更紧」——事实上如果 a=−1/2 且 −a+b=1 自动满足时，只靠可导就能推出连续。这提示一个一般原则：可导是比连续更强的局部条件，它能「自动兼容」更低阶的要求。以后学分段函数的二阶可导，就是再加一阶「曲率接头」，同一个套路叠三层。

题 26 · 主观题（10 分）

课件 2.2 P24–25

题目：练1：求函数 y = ln[1 + f²(x)] 的导数，其中 f(x) 可导。

答案：y′ = 2f(x)f′(x) / [1 + f²(x)]

解析：两层复合：ln(·) 套 1+f²(x)。y′ = [1/(1+f²(x))]·(2f(x)f′(x)) = 2f(x)f′(x)/[1+f²(x)]。

💡 思路与数学思想 · 抽象函数的链式法则

思路：抽象函数求导的纪律：求导结果中必须保留 f′(x) 这个「未知数」，并且每用一次链式法则，内层导数就要出现一次。f²(x) 对 x 求导 = 2f(x)·f′(x)——把 f(x) 整个看成「中间变量 u」，先对 u 求导再乘 u′。

隐藏的数学思想：这个形式 2f/(1+f²) 值得记住——它是 tan 的导数的「影子」：若 f(x) = tan x，则 y = ln(sec²x) = −2ln|cos x|。抽象是具体的「压缩包」：记住抽象形式，就自动记住了一整类具体函数的导数。后面学参数方程、隐函数求导，都会反复和这种「带 ′ 的表达式」打交道。

课件 2.2 P45–46

题目：练2：设 f(x) = 1/[√(1+x²)·(x+√(1+x²))]，求 f″(x)。

答案：f″(x) = 3x/(1+x²)^(5/2)

💡 思路与数学思想 · 先化简，再求导：结构识别胜过硬算

思路：高阶导数题的第一反应不该是「开算」，而是「这个函数能不能变简单」。本题的触发器是 √(1+x²)+x 出现在分母——这是经典的共轭结构，乘积为 1，有理化一步直接把「商」变「差」，函数塌缩成 1 − x/√(1+x²)。原式求二阶导要连用商的法则、链式法则、乘积法则，草稿半页纸；化简后只剩一个幂函数的逐层求导，四行结束。计算前花三十秒观察结构，通常能省三十分钟。

隐藏的数学思想：① 共轭对 √(1+x²)±x 不是偶然的技巧对象：令 x = sinh t，则 √(1+x²)+x = cosh t + sinh t = e^t——原函数本质是 e^(−arsh x) 的一个变形，双曲函数的指数表示才是它的「原生家庭」。数学中「看起来要硬算」的式子，多半是某个简洁结构的「伪装形态」，化简就是「认出它」。② 更深一层：求导是「破坏结构」的操作（越导越复杂是常态），所以高阶导数的艺术全在「动手前先把函数整理成抗导的形式」。这与积分的思想正好对偶——积分是「重建结构」。一讲一搭，构成微积分的美学核心。

题 28 · 单选题（5 分）

课件 2.4 P16

题目：若方程 y sin x − cos(x−y) = 0 确定隐函数 y = y(x)，则 y′ = (　)

选项：

  • A. (y cos x + sin(x−y)) / (sin(x−y) − sin x)
  • B. −(y cos x + sin(x−y)) / (sin(x−y) − sin x)
  • C. (sin(x−y) − sin x) / (y cos x + sin(x−y))
  • D. −(sin(x−y) − sin x) / (y cos x + sin(x−y))

答案：A

解析：两边对 x 求导（y = y(x)）：

y′ sin x + y cos x + sin(x−y)·(1−y′) = 0
y′[sin x − sin(x−y)] = −[y cos x + sin(x−y)]
y′ = −(y cos x + sin(x−y))/(sin x − sin(x−y))
   = (y cos x + sin(x−y))/(sin(x−y) − sin x)

💡 思路与数学思想 · 隐函数求导的「纪律」

思路：这道题（与 §12 题 33 同源，课件 2.4 与 2.5 各出现一次，可见其「地位」）的得分点全在细节：① cos(x−y) 对 x 求导，内层 x−y 的导数是 1−y′（y 也是 x 的函数！），于是 −sin(x−y)·(1−y′) 里同时长出含 y′ 和不含 y′ 的两项——隐函数求导的方程总是这样。② 最后一步「解 y′」只是代数整理：含 y′ 的挪左边，不含的挪右边，提出 y′。四个选项的差别只在符号与分子分母倒置——按部就班算一遍，对号入座即可。

隐藏的数学思想：「y 是 x 的函数」这七个字是整章的灵魂。显函数求导是「顺着链条走」，隐函数求导是「戴着镣铐跳舞」：y 不能解出来，但它的「变化律」y′ 参与运算，最后把 y′ 解出来即可——我们不需要知道 y 长什么样，只需要知道它「怎么变」。这个思想在后面一阶微分、全微分、隐函数存在定理中会不断放大：现代数学大量研究「关系的导数」而非「对象的显式表达式」。

💡 思路与数学思想 · 对数求导：log 的「降级」魔法

思路：识别信号：函数是「一箩筐因子相乘相除」——(x+1)、三次根号、(x+4)²、e^x。若用商法则 + 链式法则硬算，四个因子互相纠缠，极易丢项。对数求导的战术：先取 ln，让 log 把「乘除幂」全部降级成「加减乘」，得到一串简单分式之和，逐项求导后乘回 y。

💡 思路与数学思想 · 参数方程：换「币种」的汇率

思路：两个易错点，课件用选项分别「埋了雷」：① 二阶导必须再除一次 dx/dt——因为 d(dy/dx)/dt 是「对 t 的导数」，而题目要「对 x 的导数」，中间隔着汇率 1/(dx/dt)。漏了它就会掉进选项 A 的坑（A 正是通式）。② 审题：题目问的是 t=0 处的值，不是通式——算出通式后必须代值。选项 A = 通式、D = 一阶导通式、C = 一阶导在 0 的值，三个选项分别对应三种典型失误。

隐藏的数学思想：参数方程求导的本质是换坐标系：曲线本身没变，只是「尺子」从 x 换成了 t。所有导数在换尺子时都要乘「坐标变换的汇率」（此处即 1/(dx/dt)）——这个「汇率」在多元微积分里会升级成雅可比矩阵，在微分几何里就是「换基」。一维的参数方程是这一切最简单的原型：dy/dx = (dy/dt) ÷ (dx/dt)，链式法则的「除法形态」。另外注意约分 (1−t) 的处理：t=1 时 0/0 是假性间断，约分后 (3/2)(1+t) 在 t=1 处极限为 3——先化简再求值的老朋友又出现了。

题 32 · 课后习题 4

课件 2.4 P56

题目：试从 dx/dy = 1/y′ 导出： (1) d²x/dy² = −y″/(y′)³；(2) d³x/dy³ = [3(y″)² − y′y‴]/(y′)⁵

答案：推导见解析

解析（课件解法）：

(1) d²x/dy² = (d/dy)(1/y′) = (d/dx)(1/y′)·(dx/dy) = −y″/(y′)²·(1/y′) = −y″/(y′)³。

(2) d³x/dy³ = (d/dy)[−y″/(y′)³] = −[y‴(y′)³ − y″·3(y′)²y″]/(y′)⁶·(1/y′) = [3(y″)² − y′y‴]/(y′)⁵。

💡 思路与数学思想 · 反函数高阶导数：链式法则的连锁应用

思路：「对 y 求导」不会算？全部「兑换」成「对 x 求导」再乘汇率 dx/dy = 1/y′——和题 31 完全同一个动作，只是这次换的方向相反（x 当 y 的函数）。二阶导兑换一次汇率，三阶导兑换两次，分母的幂次一层层叠（³→⁵）。

隐藏的数学思想：① 变量角色的相对性：谁是自变量只是「视角」选择。把 x 看成 y 的函数后，整个导数结构「镜像对称」——反函数求导公式 1/y′ 只是这个对称性的一阶影子，本题两个公式是二阶、三阶影子。② 微分形式不变性（见 §12 题 34）：d/dy = (dx/dy)·d/dx 无论 y 是不是自变量都成立——「兑换」永远合法。这是莱布尼茨记号最美的地方：分数形态的链式法则让换元「看起来就像约分」，而它其实是对的。③ 这对公式在参数方程求高阶导、反函数作图、乃至微分方程的变量代换里都是常客，值得手推两遍直到形成肌肉记忆。

§12 函数的微分（3 题）

📇 讲解卡片 · 微分的概念与应用

项目 要点
定义 Δy = f′(x₀)Δx + o(Δx)，线性主部 dy = f′(x₀)Δx 称为微分。可微 ⇔ 可导
两个变量 dy 与 x 和 Δx 都有关；导数 f′(x) 只与 x 有关
形式不变性 dy = f′(u)du 无论 u 是自变量还是中间变量；但 x 不当自变量时 dx ≠ Δx（dx 是另一个微分）
隐函数求微分 两边求微分往往比求导再乘 dx 更顺：d(uv) = u dv + v du 自动带出 dx 与 dy 的关系

题 33 · 单选题（5 分）

课件 2.5 P26

题目：练1：设函数 y = y(x) 由方程 y sin x − cos(x−y) = 0 所确定，求 dy/dx。

选项：

  • A. (y cos x + sin(x−y)) / (−sin x)
  • B. (y cos x + sin(x−y)) / sin x
  • C. (y cos x + sin(x−y)) / (sin(x−y) − sin x)
  • D. (y cos x + sin(x−y)) / (sin(x−y) + sin x)

答案：C

解析：与题 28（课件 2.4 P16）同一方程，详解见该题。答案为 (y cos x + sin(x−y))/(sin(x−y) − sin x)。同一道题在「隐函数求导」与「微分」两章各出现一次——课件在提醒：求导和微分是同一件事的两种记法。

题 34 · 主观题 · 思考

课件 2.5 P38–39

题目：思考：

  1. 函数 f(x) 的导数 f′(x) 与微分 f′(x)Δx 是否与 x 和 Δx 都有关？
  2. 在微分表达式 dy = f′(x)dx 中，当 x 为自变量时 dx = Δx；当 x 不为自变量时，dx = Δx 是否仍旧成立？

答案：1. 导数只与 x 有关，微分与 x 和 Δx 都有关；2. x 不为自变量时 dx ≠ Δx

解析（课件解答）：① 导数 f′(x) 是函数在 x 处的「斜率」，只取决于位置 x；微分 dy = f′(x)Δx 是「用这条斜率走一步 Δx 的线性估计值」，位置和步长两个因素决定。② 例如 y = f(x)，x = g(t)：dy = f′(x)dx，dx = g′(t)dt——此时 dx 是中间变量 x 的微分（≈ Δx 但不等于），「dx = Δx」只是自变量增量的记号约定。

💡 思路与数学思想 · 微分形式不变性

隐藏的数学思想：「dx = Δx」从来不是数学定理，而是记号约定——把自变量的增量命名为 dx。一旦 x「退位」成中间变量，dx 就还原成它本来的身份：另一个线性主部（≈Δx）。dy = f′(u)du 的「形式不变性」是莱布尼茨留下的最深遗产：微分式像多项式一样可以「换元约分」，而不必管谁是自变量。整个链式法则 dy/dx = (dy/du)(du/dx) 之所以能像分数一样「约」，底气就在于此。本题的两个思考题，一个辨「导数 vs 微分」，一个辨「约定 vs 本质」——都是卷面上的概念题常客。

题 35 · 主观题（10 分）

课件 2.5 P42

题目：由 x²y − e^(2y) = sin y 确定 y = y(x)，求 dy。

答案：dy = [2xy/(2e^(2y) + cos y − x²)] dx

解析（两边求微分）：

d(x²y) − d(e^(2y)) = d(sin y)
2xy dx + x² dy − 2e^(2y) dy = cos y dy
(x² − 2e^(2y) − cos y) dy = −2xy dx
dy = −2xy/(x² − 2e^(2y) − cos y) dx = 2xy/(2e^(2y) + cos y − x²) dx

💡 思路与数学思想 · 两边求微分：自动成对

思路：题目要的是 dy（不是 y′），此时「两边求微分」往往比「两边求导再乘 dx」少一步：d(x²y) = 2xy dx + x² dy——乘积的微分法则自动把 dx、dy 成对地带出来，最后按 dx、dy 归类整理即得。e^(2y) 的微分 2e^(2y)dy、sin y 的微分 cos y dy 都直接写出，无需显式提 y′。

隐藏的数学思想：「两边求微分」的合法性来自微分形式不变性（题 34 刚复习过）：不管 y 是不是自变量，d(等式) 都成立。这与「两边求导」在哲学上等价，但微分记号让「y 也是变量」这件事变得显式——dy 堂堂正正地出现在式子里，和 dx 平起平坐。记号即思想：莱布尼茨的 d 记号把「变化」本身变成了可以运算的对象，这正是「微分方程」整门学问的起点。
